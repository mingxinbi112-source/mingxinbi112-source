## 我在做什么

把「反复使用、真正解决问题的思考框架」沉淀成**可安装、可复用、可沉淀**的 Agent 技能:

- **12 个剖析动作** — 5 大场景:问清问题① → 学习②③④⑤ → 解决问题⑥⑦⑧ → 决策⑨⑩ → 认识自己⑪⑫
- **1 套认知操作系统** — 四条铁律，每条都来自一次真实翻车:反方辩手 · 先验证再构建 · 想着系统化 · 盯推→拉
- **1 个企业级方法论** — FDE:AI 在企业 / B 端怎么真正落地(Go/No-Go 评估、权限禁区、决策闭环)

## 5 大场景 15 个技能

| 场景 | 技能 |
|---|---|
| 问清问题 | 苏格拉底式提问 |
| 学习 | 双层解释法 · 反向拆解 · 横纵分析法 · 事实核查 |
| 解决问题 | 专家会诊 · 第一性原理 · 跨领域借解 |
| 决策 | 双向钢人论证 · 最小实验 |
| 认识自己 | 天赋挖掘 · 人生设计术 |

## 我的工作方式(四条铁律)

1. **反方辩手滤镜** — 先质疑假设、找盲区、压力测试，不当 yes-man
2. **先验证再构建** — 想法先用问题澄清验证，不急着执行
3. **想着系统化** — 复杂问题存成技能，环境知识存进记忆，workaround 写进 pitfalls
4. **盯推→拉** — 好方案 = 用户不用反复提醒，让系统自动拉
